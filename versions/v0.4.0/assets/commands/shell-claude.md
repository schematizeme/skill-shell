da casa, a partir de `.claude/skills/schematize-shell/assets/CLAUDE.md`.

**atualize-a** e diga o que mudou. O `CLAUDE.md` é sempre-on: ele vale para toda sessão neste repo,
sem ninguém precisar lembrar de carregar a skill.
